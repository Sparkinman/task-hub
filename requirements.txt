# Task Hub — Python dependencies
#
# Every version is pinned exactly, and deliberately so. These are the versions
# Task Hub was built and tested against, and pinning them means the image built
# from this repository next month is the same image that was tested today.
#
# Ranges are the usual advice, and they were used here until a rebuild quietly
# moved Radicale from 3.7.8 to 3.8.0 -- a new upstream version that nobody had
# tested, arriving in the middle of a release. For software people install on a
# machine in a cupboard and then forget about, a surprise is worth more than a
# few weeks of missed patches.
#
# To take a newer version of something: change it here, run ./run-tests.sh, and
# only then commit. That is the whole process, and it is the point.
