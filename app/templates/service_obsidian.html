Two-way: this vault and the collections you tick mirror each other

Tasks in this vault go out to every collection ticked below, and every task in those collections is written back into this vault — including ones that came from Google, Todoist, your phone or your Supernote. New tasks arrive as {% if fmt == 'tasknotes' %} task notes, one file each, in {{ entry.tasks_folder or 'the folder TaskNotes uses' }}. {% else %} checklist lines in {{ entry.create_note or '— no note chosen yet, so nothing can be written in' }}. {% endif %} Change the format beside the tick in the table below.

{% else %}
One-way: tasks leave this vault, nothing comes back

Ticking a collection below sends this vault's tasks to it, and on to every other service that collection feeds. Nothing is written into your notes — not tasks from Google, not completions from Todoist.

To mirror a collection both ways, tick “Allow read & write” on the row below and choose the format you want tasks written in. Until you do, Obsidian's own client stays in mirror-remote mode, which reverts anything written locally — so this is not a promise Task Hub is making, it is one the client enforces.
