How to get a tunnel token (about 3 minutes, one time)

You need a domain name already set up in Cloudflare. This is free.

  1. Go to one.dash.cloudflare.com and sign in.
  2. In the left menu choose Networks → Tunnels.
  3. Click Create a tunnel, then Cloudflared, and give it a name such as taskhub. Click Save tunnel.
  4. On the next page choose the Docker tab. A command appears containing a very long string starting eyJhIjoi… — copy everything after --token. That is your token.
  5. Click Next. Fill in the public hostname:
    • Subdomain: anything you like, e.g. tasks
    • Domain: your domain
    • Type: HTTP
    • URL: taskhub:8080
  6. Click Save tunnel, paste the token above, tick the box and press Save.

The address box takes taskhub:8080 with no http:// in front — Cloudflare adds that from the Type dropdown. It is the name of this application on its own private network, so no IP addresses are involved and nothing breaks when they change.

Afterwards, set Public address above to https:// plus the hostname you chose, so the CalDAV addresses on the Radicale tab are ones your devices can reach.

What Task Hub clears up on its own

After every sync it trims its own history: sync runs are kept while they are among the most recent 200 or less than 30 days old, so neither a quiet fortnight nor a busy day can erase it. Log lines go with the run they belong to.

Records of deleted tasks are kept for 90 days. They stop a service that has not caught up from recreating something you deleted, so they are held well past the point of usefulness — the row is tiny and a resurrected task is not.

Deliberately never swept up: the links recording that one of your tasks is a particular task in a service. Removing one while both sides still exist would make the next sync create a duplicate, so they are only ever removed when the thing at one end has actually gone.
