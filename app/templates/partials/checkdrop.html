{# A dropdown whose contents are checkboxes. Plain columns of switches stop working once the choices run into the dozens, which is exactly what happens when write-back targets are drawn from every connected service rather than one account. This collapses them to a single control that reports how many are ticked and opens on click. Built on
, so it opens and closes with no JavaScript at all; the script only keeps the summary count current as boxes are ticked, and the markup degrades to an always-open list if it never runs. #} {% macro checkdrop(name, groups, selected, empty_label, noun) -%} {%- set ns = namespace(count=0, total=0) -%} {%- for group in groups -%} {%- for option in group.options -%} {%- set ns.total = ns.total + 1 -%} {%- if option.value in selected -%}{%- set ns.count = ns.count + 1 -%}{%- endif -%} {%- endfor -%} {%- endfor -%}
{%- if ns.count == 0 -%} {{ empty_label }} {%- else -%} {{ ns.count }} {{ noun }}{{ '' if ns.count == 1 else 's' }} {%- endif -%}
{%- if ns.total == 0 %}
Nothing to choose from yet.
{%- endif %} {%- for group in groups %} {%- if group.label %}
{%- if group.colour %} {%- endif %} {{ group.label }}
{%- endif %} {%- for option in group.options %} {%- endfor %} {%- endfor %}
{%- endmacro %}
