Setting this up on iPhone, Android, macOS or Thunderbird

iPhone / iPad: Settings → Apps → Calendar → Calendar Accounts → Add Account → Other → Add CalDAV Account. Put the address above in "Server", then your username and password.

macOS: Calendar → Settings → Accounts → + → Other CalDAV Account → Account Type "Manual", then the same details.

Android: Install DAVx⁵, add a "Login with URL and user name" account using the address above.

Thunderbird: Calendar → New Calendar → On the Network → CalDAV, then paste the address.

If Task Hub is only reachable on your home network, these clients will only sync while the device is on that network. To sync from anywhere, Task Hub needs a public address — set it under Settings so the address shown here matches.
